# PS5X360E

PS5X360E is an experimental fork of [PS5X360](https://github.com/BrinooTk/PS5X360) by BrinooTk, an Xbox 360 emulator for jailbroken PlayStation 5 consoles built on [Xenia Canary](https://github.com/xenia-canary/xenia-canary). This fork brings fixes from [Xenia Edge](https://github.com/has207/xenia-edge) by has207 into PS5X360, starting with games that run in Xenia Edge but not in PS5X360, such as Need for Speed: The Run. It is a work in progress: expect crashes, missing features and broken games. Please report problems with this fork here, not to the PS5X360, Xenia Edge or Xenia Canary projects.
